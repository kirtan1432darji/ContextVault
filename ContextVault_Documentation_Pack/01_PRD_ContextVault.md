# ContextVault PRD

## Overview
AI-powered Screenshot Knowledge Workspace.

## Goals
- Automatic screenshot detection.
- On-device OCR.
- Smart folder organization.
- Context generation.
- AI chat with screenshot knowledge.

## Target Users
Developers, QA Engineers, Students, Project Managers, Professionals, and Custom Folder users.

## Key Features
1. Screenshot detection.
2. OCR.
3. Smart folders.
4. Context folders.
5. Semantic search.
6. AI Chat.

## Success Metrics
- Screenshot auto-processing success rate.
- OCR accuracy.
- Classification accuracy.
- Search response time.
