# ContextVault TRD

## System Architecture
Frontend: React Native (TypeScript)
Backend: FastAPI (Python)
Database: SQL Server + SQLite
Authentication: JWT + Refresh Tokens
OCR: Google ML Kit

## Integrations
- MediaStore screenshot observer.
- ML Kit OCR.
- FastAPI REST APIs.

## Security
- Zero image upload.
- SHA256 fingerprinting.
- HTTPS + JWT.

## Deployment
Android APK, SQL Server 2022, FastAPI.
